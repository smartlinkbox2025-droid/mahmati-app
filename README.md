# مهمتي

تطبيق عربي شخصي وبسيط لإدارة المهام اليومية والمشاريع الصغيرة.

## فتح التطبيق

بعد نجاح النشر، افتح:

https://smartlinkbox2025-droid.github.io/mahmati-app/

## المزايا

- إضافة وتعديل وحذف المهام.
- تحديد الموعد والأولوية والملاحظات.
- تنظيم المهام داخل مجلدات.
- البحث والتصفية حسب الأولوية.
- متابعة المهام المكتملة.
- حفظ البيانات محليًا داخل المتصفح.
- دعم التثبيت على شاشة الجوال.

## التطوير محليًا

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/mahmati run dev
```

النسخة المنشورة حاليًا موجودة في جذر فرع `main` ويتم تقديمها عبر GitHub Pages.
